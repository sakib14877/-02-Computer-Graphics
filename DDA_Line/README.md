# DDA Line Drawing Algorithm

## Objective

Draw a straight line using the DDA (Digital Differential Analyzer) algorithm with OpenGL (GLUT).

## Language

- C++

## Graphics Library

- OpenGL
- GLUT

## Algorithm

1. Read starting point (x1, y1).
2. Read ending point (x2, y2).
3. Calculate dx and dy.
4. Find the number of steps.
5. Calculate x increment and y increment.
6. Plot pixels one by one.

## Output

The program draws a straight line between two points.
